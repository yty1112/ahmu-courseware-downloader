# 安医教学平台课件下载助手

一个跑在浏览器里的轻量脚本：在安徽医科大学教学平台（`mobile.ahmu.edu.cn`）的课程页右下角放一个小面板，把整门课的课件、讲义、视频**一次性列出来**，点一下就能下载，不用一个个点开预览页再复制链接。

## 它解决什么问题

平台原生的下载较麻烦，常无法下载
这个脚本直接走平台自己的接口，跳过所有页面操作，操作方便：

| 传统做法 | 本工具 |
| --- | --- |
| 逐个点开预览页 | 一次拉取整门课清单 |
| 手动复制 / 解码地址 | 接口返回即下载 |
| 视频无下载入口 | 视频同样可保存 |
| 不知道文件多大、什么类型 | 面板显示类型徽章与大小 |

---

## 功能

- **课程级枚举**：一次请求拿到本课程全部活动的全部附件，不再逐个点开。
- **自动识别课程**：从 URL 解析课程号，SPA 路由切换时自动重扫，不用手动刷新。
- **会话自动捕获**：运行时 hook `XHR` / `fetch`，自动拿到平台使用的 `x-session-id` 请求头，无需手动贴 token。
- **分组浏览**：`全部 / 文档 / 视频` 三个页签，按活动标题分组，带 PDF / PPT / 文档 / 表格 / 视频 / 音频 / 压缩包彩色徽章。
- **大文件流式保存**：视频、音频或大于 20 MB 的文件走隐藏 iframe 流式下载，不占内存、不被弹窗拦截、保留原文件名；小文件走 `fetch + blob`，同样保留文件名。
- **批量下载**：按当前分组一键排队，逐个下载并显示进度。
- **多副本自保护**：同一页面装了多个副本时，只有版本号最高的那份生效，不会出现两个面板。
- **零依赖**：单文件、无框架、无 `@grant` 权限、不读取 Cookie、不上传任何数据。

## 工作原理

```
页面 URL  /course/{课程号}/courseware
   │
   ├─ ① 解析课程号
   │
   ├─ ② GET /api/courses/{课程号}/activities        ← 带 x-session-id 请求头
   │      └─ 返回 activities[].uploads[]（文件名、id、大小、allow_download）
   │
   └─ ③ GET /api/uploads/{文件id}/url               ← 逐个取真实地址
          └─ 返回 https://media.ahmu.edu.cn/download/file/...
                 └─ 视频 → 隐藏 iframe 流式保存
                 └─ 小文件 → fetch blob + a.download
```

平台把 `x-session-id` 放在请求头而非 Cookie 里，脚本因此包装了 `XMLHttpRequest.prototype.setRequestHeader` 与 `window.fetch`，捕获第一次出现的该请求头；接口跨域返回通配 CORS，所以请求统一使用 `credentials: 'omit'`。

脚本**不解析任何页面 DOM**，也不对下载链接做二次解码——所有数据都来自接口本身。

## 使用

1. 登录平台，进入任意课程页。
2. 等 1～9 秒，右下角面板自动出现并显示「识别到 N 个文件」。
3. 用 `全部 / 文档 / 视频` 切换分组；单条点「下载」，或点「下载当前分组全部」批量下载。
4. 文件保存到浏览器默认下载目录，文件名与平台上一致。

面板状态行会显示进度与结果，例如「已保存 xxx.mp4」「完成：成功 12，失败 0」。

### 关于视频上的「禁」标

平台对视频类资源返回 `allow_download: false`，页面上因此没有下载入口，但 `/api/uploads/{id}/url` 仍然返回真实地址，按钮文案显示为「试下」。**是否使用请自行判断**——这属于平台意愿与接口行为的差异地带，见下方合规说明。

## 常见问题

**面板没有出现 / 一直「等待页面进入课程」**
脚本在页面加载 800 ms 后开始扫描，若此时 SPA 还没进到课程页会以 600 ms 间隔重试 20 次。仍失败时，点面板底部「重新扫描」，或确认 URL 里确实带课程号。

**一直「等待平台会话」**
说明还没捕获到 `x-session-id`。正常登录并打开一次课程内容即可；若平台改了鉴权方式，需要更新脚本。

**一次装了好几个副本**
脚本内置版本守卫，只有最高版本生效。建议在管理器里删掉旧副本，避免混淆。

**下载失败**
视频多为大文件，请确认网络与磁盘空间；若浏览器拦截了下载，允许该站点下载即可。

## 兼容性与移植

本脚本只针对安徽医科大学平台，以下内容与站点绑定，换学校需要重新适配：

- `@match *://*.ahmu.edu.cn/*`
- API 根地址 `https://lms.ahmu.edu.cn`
- 接口路径 `/api/courses/{id}/activities`、`/api/uploads/{id}/url`
- 鉴权头 `x-session-id`
- 返回字段名与文件域名 `media.ahmu.edu.cn`

方法论是可复用的（运行时捕获凭证、课程级枚举、SPA 重扫、大文件流式保存、类型识别），但取数部分需要按目标平台的真实请求重写。若对方也是同一套商业 LMS，通常改上述几处常量即可跑通；若是 Canvas / Moodle / Blackboard 一类，属于重写。
